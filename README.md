# VNeTraffic dành cho Home Assistant

Tích hợp tùy chỉnh Home Assistant để truy vấn lịch sử vi phạm giao thông từ API VNeTraffic.

## Installation

### HACS
1. Thêm kho lưu trữ này làm kho lưu trữ HACS tùy chỉnh (Tích hợp).
2. Cài đặt VNeTraffic .
3. Khởi động lại Home Assistant.
4. Vào **Cài đặt → Thiết bị và dịch vụ → Thêm tích hợp → VNeTraffic**.
5. Nhập **user, password của VNeTraffic và biển số xe của bạn vào tài khoản VNeTraffic** .
